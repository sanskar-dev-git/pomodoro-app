# ⏱️ Pomodoro — Focus & Productivity App
🚀 **Live Demo:** [pomodoro-app-smoky-eight.vercel.app](https://pomodoro-app-smoky-eight.vercel.app/)
A sleek, modern, single-page Pomodoro timer web application built with **React**, **Tailwind CSS**, and **HTML5 Canvas**. Designed for frictionless productivity, it features built-in ambient sound generators, state-driven color themes, and a dynamic starfield hyperdrive animation.

---

## ✨ Features

* ⏱️ **Core Pomodoro Timer**: Seamless toggling between **Work (25m)**, **Short Break (5m)**, and **Long Break (15m)** with automated session tracking.
* 🧠 **40 Hz Binaural Deep Focus**: Built-in Web Audio API synthesizer that generates a 40 Hz Gamma wave binaural tone to enhance cognitive focus and working memory, alongside Rain and Cosmic ambience.
* 🌌 **Interactive Starfield Canvas**: Custom HTML5 Canvas starfield that dynamically accelerates into warp speed during active focus sessions.
* 🎨 **State-Driven Themes**: Visual transitions based on industry design standards—Warm Crimson for Work, Emerald Green for Short Breaks, and Indigo Blue for Long Breaks.
* 📱 **Viewport-Aware Responsive UI**: Scaled dynamically so the entire dashboard fits on one screen without vertical scrolling across all screen sizes.

---

## 🛠️ Tech Stack

* **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Graphics**: HTML5 Canvas API
* **Audio**: Web Audio API (Synthesizers & Noise Generators)
